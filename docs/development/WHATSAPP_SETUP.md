# হোয়াটসঅ্যাপ নোটিফিকেশন সেটআপ গাইড

আপনার ফাউন্ডেশন অ্যাপ থেকে ফ্রি-তে হোয়াটসঅ্যাপ মেসেজ পাঠানোর জন্য নিচের ধাপগুলো অনুসরণ করুন:

### ১. মেটা ডেভেলপার অ্যাকাউন্ট তৈরি
- [Meta for Developers](https://developers.facebook.com/) পোর্টালে যান এবং লগইন করুন।
- **Create App** বাটনে ক্লিক করুন।
- **Other** > **Business** সিলেক্ট করে অ্যাপের একটি নাম দিন।

### ২. হোয়াটসঅ্যাপ প্রোডাক্ট যুক্ত করা
- অ্যাপ ড্যাশবোর্ডে গিয়ে **WhatsApp** সেকশনে **Set up** বাটনে ক্লিক করুন।
- আপনার একটি বিজনেস অ্যাকাউন্ট তৈরি করতে হবে (যদি না থাকে)।

### ৩. এপিআই ক্রেডেনশিয়াল সংগ্রহ
- বাম দিকের মেনু থেকে **WhatsApp** > **API Setup**-এ যান।
- এখানে আপনি **Temporary access token** এবং **Phone number ID** দেখতে পাবেন।

### ৪. এনভায়রনমেন্ট ভেরিয়েবল সেট করা
আপনার প্রজেক্টের `.env.local` ফাইলে নিচের দুটি লাইন যোগ করুন:

```env
WHATSAPP_ACCESS_TOKEN=আপনার_টোকেন_এখানে
WHATSAPP_PHONE_NUMBER_ID=আপনার_আইডি_এখানে
```

### ৫. টেস্ট মেসেজ পাঠানো
- **API Setup** পেজে আপনার নিজের ফোন নম্বরটি "To" ফিল্ডে যোগ করে একটি টেস্ট মেসেজ পাঠান।
- মনে রাখবেন, ফ্রি টায়ারে আপনি মাসে ১০০০টি মেসেজ পাঠাতে পারবেন।

**বিঃদ্রঃ:** টেম্পোরারি টোকেন ২৪ ঘণ্টা পর এক্সপায়ার হয়ে যায়। স্থায়ীভাবে ব্যবহারের জন্য আপনাকে একটি **Permanent Access Token** তৈরি করতে হবে (Meta Business Settings থেকে)।
