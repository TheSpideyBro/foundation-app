# দৌলখাঁড় পূর্বপাড়া হিলফুল ফুযুল ফাউন্ডেশন — হিসাব খাতা

Fund management web app for tracking member donations and expenses.
Next.js + Supabase + Tailwind CSS.

## Setup

See [SETUP.md](./SETUP.md) for full setup instructions (Supabase schema, env vars, first admin account, deployment).

## Quick start

```bash
npm install
cp .env.local.example .env.local   # then fill in your Supabase URL + anon key
npm run dev
```
